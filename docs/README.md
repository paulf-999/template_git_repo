# 📚 docs

For anyone looking for this repo's guides: which docs are for contributors, which are for maintainers, and where a new doc goes.

- **Contributors:** the guides at this level, such as the [Git branching strategy](git_branching_strategy.md), cover working in a repo made from this template.
- **Maintainers:** [`maintenance/`](maintenance/) covers looking after the template itself, such as file headers, and its [`quality/`](maintenance/quality/) folder holds the test and markdown quality audits.
- **New doc:** put a contributor guide at this level and a maintainer-only one under `maintenance/`, then give it a row in the [markdown quality audit](maintenance/quality/quality_audit_markdown_files.md).
